Authorized Enterprise Subprocessors Directory

PocketParent engages certified enterprise subprocessors to provide cloud infrastructure, database persistence, user authentication, and message routing:

  • Google Cloud Platform (GCP): Encrypted Cloud Firestore Database & Hosting (ISO 27001, SOC 2 Type II, COPPA Compliant).
  • Firebase Authentication & Google Sign-In: User Session Verification & Security Tokens (ISO 27001, SOC 1/2/3, GDPR DPA).
  • Firebase Storage: Encrypted Media Storage for optional chore proof photos (AES-256 at Rest, SOC 2 Type II).
  • Firebase Cloud Messaging (FCM): Real-time Push Notification Delivery (ISO 27001, SOC 2).

Data Protection Agreements (DPAs)

All listed subprocessors operate under legally binding Data Protection Agreements (DPAs) guaranteeing full compliance with GDPR Standard Contractual Clauses (SCCs), CCPA/CPRA, and COPPA data processing regulations.
